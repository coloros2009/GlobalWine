
# Global Wine for Android

**Global Wine** — это эмулятор Windows-игр и приложений для Android на базе Termux с поддержкой Wine, DXVK, Box86/Box64, WoW64 и Turnip (Vulkan).

Запускай PC-игры на Android прямо через эмуляцию и Vulkan-ускорение!

## Установка

Открой Termux и выполни команду:

curl -s -o ~/x https://raw.githubusercontent.com/coloros2009/GlobalWine/main/install && . ~/x
